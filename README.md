## 提交三样（缺一不可）

1. **作品说明文档** —— 选题背景、功能介绍、**AI 使用情况说明**
2. **演示视频** —— 3–5 分钟
3. **成品** —— 可运行代码包（须附运行说明：开发环境 / 依赖 / 启动方式），**或**一个能访问的线上链接（评审期间须可访问）

> 只完成部分功能的，必须在文档里写明「已实现范围」与「未实现部分」。

## 评分维度

| 维度 | 打法 |
|---|---|
| 技术实现 | 主流程真能跑，不是 PPT |
| 完成度与可用性 | 功能范围可以小，但必须闭环 |
| 创新性 | 切入点新，不是套壳聊天框 |
| 实用价值与落地潜力 | 对着学校信息化真实需求做 |
| 现场演示效果 | 5 分钟演示 + 5 分钟答辩，视频要排练 |

线上初审按「完整性、方向契合度、可运行性」筛入围。**可运行性是硬门槛。**
